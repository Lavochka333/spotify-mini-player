# Spotify Mini Player

Прозрачный мини-плеер и музыкальный визуализатор для Windows 10/11. Небольшой виджет поверх других окон показывает текущий трек Spotify, обложку и спектр системного звука. Его можно перетащить в удобное место или переключить в компактный режим.

## Установка

1. Откройте [последний релиз](https://github.com/Lavochka333/spotify-mini-player/releases/latest) и скачайте **setup.exe**.
2. Запустите установщик и выберите папку установки.
3. Откройте **Spotify Mini Player** через меню «Пуск» или ярлык на рабочем столе.
4. Запустите воспроизведение в настольном Spotify.

Поддерживается Windows 10/11 **x64**. Node.js для установленной программы не требуется. Spotify устанавливается отдельно. Установщик добавляет программу в список установленных приложений Windows, откуда её можно удалить.

## Возможности

- Название композиции, исполнитель и обложка из медиасессии Windows.
- Предыдущий трек, Play/Pause и следующий трек.
- Прозрачное окно поверх других приложений с сохранением положения.
- Полный и компактный режимы.
- Полосы, зеркальный спектр, звуковая волна и точки; цвета подстраиваются под обложку.
- Пульсация обложки под бит, настройка определения ритма и чувствительности, плавное покачивание.
- PNG, JPG, WebP и GIF в виде ASCII, цветного ASCII или исходного изображения.
- Настройка размера, прозрачности, вращения и точки опоры анимации; перетаскивание при открытых настройках.
- Автоматическое сохранение настроек и защита от запуска второго экземпляра.

Шестерёнка, сворачивание и закрытие появляются при наведении на верхнюю область карточки.

## Горячие клавиши

| Комбинация | Действие |
| --- | --- |
| `Ctrl+Shift+M` | Компактный / полный режим |
| `Ctrl+Shift+H` | Скрыть / показать виджет |

## Как это работает

Приложение использует Electron 38, Windows Global System Media Transport Controls и Chromium loopback. Метаданные Spotify читаются через `windows-media-sessions`, а системный звук анализируется Web Audio. Для определения ритма используется `aubiojs` или басовый детектор.

Spotify Web API, OAuth и токены не нужны. Если Windows не передала обложку, приложение пытается найти её через публичный iTunes Search API. Настройки хранятся в `%APPDATA%\spotify-corner-visualizer`, отдельно от файлов программы.

## Запуск из исходников

Нужны Windows x64, Node.js 20+ и npm.

```powershell
git clone https://github.com/Lavochka333/spotify-mini-player.git
cd spotify-mini-player
npm install
npm start
```

Для запуска без окна консоли используйте `Spotify Mini Player.vbs`.

## Сборка установщика

Дважды нажмите **Build Installer.bat** в папке проекта. Он установит зависимости, соберёт установщик и откроет папку `dist`. Для первой сборки нужен интернет.

Или выполните:

```powershell
npm install --include=dev
npm run build:installer
```

Готовый файл: **dist/setup.exe**. Его можно отправить другу без остальных файлов проекта. Личные настройки и выбранные пользователем изображения в сборку не входят.

| `Build Installer.bat` | Сборка установщика двойным щелчком |

## Ограничения

Визуализатор анализирует весь звук устройства вывода Windows. Spotify должен зарегистрировать медиасессию — обычно после начала воспроизведения. Системные кнопки могут управлять другим приложением, если оно стало активной медиасессией. Полный 3D-оборот плоской ASCII-анимации сжимает её при боковом ракурсе.

Неофициальный проект, не связанный со Spotify.
